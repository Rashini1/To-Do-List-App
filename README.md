# 📝 To-Do List App

A simple and elegant **To-Do List App** built using **Python (Tkinter)** to help you manage daily tasks easily.  
Add, delete, and mark tasks as completed — all in a beautiful, user-friendly interface.

---

## Features

✅ Add new tasks easily  
✅ Mark tasks as completed  
✅ Delete selected tasks  
✅ Save and load tasks automatically  
✅ Clean and minimal Tkinter UI  

## ⚙️ Tech Stack

- **Language:** Python 3  
- **GUI Framework:** Tkinter  
- **File Storage:** Local text file (`tasks.txt`)
